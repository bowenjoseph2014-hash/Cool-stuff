# 🎮 Cool Stuff Hub

A fun, interactive website featuring random games and utilities!

## Features

### 🎯 Memory Game
A classic memory flip card game. Match all pairs in the fewest moves possible!
- 16 cards with 8 matching pairs
- Move counter
- Match tracker
- Victory message when complete

### 💡 Random Facts
Learn interesting and surprising facts about the world. Click the button to get a new fact each time!

### 🛠️ Fun Tools

#### 🎲 Dice Roller
Roll different types of dice:
- d6 (6-sided dice)
- d20 (20-sided dice)
- d100 (100-sided dice)

#### 🎨 Color Generator
Generate random colors in hex format. Perfect for design inspiration!

#### 🃏 Coin Flip
Flip a coin for heads or tails with an animated effect.

## How to Use

1. Open `index.html` in your web browser
2. Use the navigation tabs at the top to switch between different games and tools
3. Click on any button to interact with the features

## Project Structure

- `index.html` - Main HTML structure
- `style.css` - All styling and animations
- `script.js` - Game logic and interactivity

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (no frameworks)

Works on all modern browsers:
